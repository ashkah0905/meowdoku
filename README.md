# Meowdoku

ネコを探す、マインスイーパ風のロジックパズルです。画面上のタイトルは「Meow Logic」です。ブラウザで `index.html` を開くだけで遊べます。

## ルール

- 1色につきネコは1匹
- 各行にネコは1匹
- 各列にネコは1匹
- ネコ同士は上下左右斜めに隣接できません

## 遊び方

1. `index.html` をブラウザで開き、ホームの「つづける」を押す
2. マスをタップして×を置く。もう一度タップすると空に戻る
3. ネコがいると思う空または×のマスを長押しして、ネコを置く
4. 間違った場所へネコを置くとライフが1つ減る。ライフがなくなったら「リセット」で再挑戦する
5. 盤面のすべてのネコを見つけたらクリア。ダイアログの「つづける」または盤面の「次の問題」で進む

ネコやミスの印もタップすると空に戻せます。「メモ」をオンにすると、確定していないマスに仮の×やネコを置けます。メモではライフが減りません。

キーボードではTabでマスを選び、Enter / Spaceで×、Cでネコを入力できます。Hでヒント、Rでリセット、Escapeでダイアログを閉じます。

## 機能

- 固定レベル10問と、11問目以降の問題生成
- レベル1〜6は5×5、7〜30は6×6、31〜50は7×7、51以降は8×8
- 5問ごとのHard / Super Hardステージ
- ネコ発見数、ライフ、クリア数の表示
- ネコ発見時の自動×入力のオン・オフ設定
- タップ・長押し・ドラッグによる入力
- 仮置きのメモとメモのリセット
- 理由を説明するヒント
- 残り1〜2匹をロジックで確定できる場合の「仕上げる」
- 問題のリセット、ホームへの移動、クリア後の次の問題への移動
- レベル別クリア記録と途中保存
- 次の問題名・動くネコ・ローディングバーを表示する約1.1秒の遷移画面（生成中はバーを途中で待機させ、準備完了後に最後まで進める）
- ホームで選ぶテーマ（端末に合わせる／ライト／ダーク）。設定は進行状況と別に保存
- キーボード操作とスマホ幅向けレイアウト

生成問題はレベル番号から決まるseedを使い、一意解とロジックで解けることを確認して採用します。生成した問題はlocalStorageに保存し、先の問題を事前に準備します。利用できる場合はWeb Workerで生成し、Workerが使えない場合はメインスレッドで生成します。

保存できない場合もそのページでは遊び続けられますが、保存失敗の案内が表示されます。再読み込みすると、今回の進行状況が失われる可能性があります。

## 構成

- `index.html`: 画面構造
- `styles.css`: 見た目とレスポンシブ対応
- `theme.js`: 初期テーマの適用、端末設定への追従、テーマ選択と保存
- `levels.js`: 固定レベルの定義
- `rules.js`: 座標変換とルール判定
- `solver.js`: ヒント探索と自動解答
- `level-analyzer.js`: 解法と難易度の解析
- `level-generator.js`: seedに基づく一意解の問題生成
- `progression.js`: レベル番号に応じた盤面サイズ・難易度・seed
- `level-worker.js`: Workerでの問題生成
- `generated-level-store.js`: 生成問題の検証と保存・読み込み
- `game-state.js`: ゲーム状態の生成・検証・保存
- `main.js`: 入力、判定、画面遷移、保存、描画
- `tests/`: ルール、解法、固定・生成問題、保存データ、画面制御の回帰テスト
- `tests/helpers/main-harness.cjs`: DOM・保存先・Worker・タイマーを制御して実際の画面制御コードを実行するテスト補助

## テスト

Node.jsが利用できる環境で `npm test` または `node --test` を実行します。ブラウザでの実際の見た目・入力操作は別途確認します。
