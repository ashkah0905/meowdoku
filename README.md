# Meowdoku

ネコを探す、マインスイーパ風のロジックパズルです。ブラウザで `index.html` を開くだけで遊べます。

## ルール

- 1色につきネコは1匹
- 各行にネコは1匹
- 各列にネコは1匹
- ネコ同士は上下左右斜めに隣接できません

## 遊び方

1. `index.html` をブラウザで開く
2. マスをタップして `空 -> × -> ネコ -> 空` の順に切り替える
3. ネコがいないと思うマスには `×` を置く
4. ネコがいると思うマスにはネコを置く
5. 間違った場所へネコを置くとライフが1つ減る
6. 5匹すべて見つけたらクリア

## 機能

- 5x5盤面
- 固定レベル6問
- ネコ発見数表示
- ライフ表示
- 自動×入力のオン・オフ設定
- ヒント
- リセット
- レベル切り替え
- クリア状況付きレベル選択
- レベル別クリア記録
- `localStorage` による途中保存
- スマホ幅向けレイアウト

## 構成

- `index.html`: 画面構造
- `styles.css`: 見た目とレスポンシブ対応
- `levels.js`: レベル定義
- `rules.js`: 座標変換とルール判定
- `solver.js`: ヒント探索と自動解答
- `game-state.js`: ゲーム状態の生成・検証・保存
- `main.js`: 入力、判定、保存、描画
- `tests/levels.test.js`: 問題データと一意解の検証
- `tests/rules.test.js`: ルール判定の検証
- `tests/game-state.test.js`: 保存データの検証
- `tests/solver.test.js`: ヒントと自動解答の検証

## テスト

Node.jsが利用できる環境で実行します。

```sh
npm test
```
