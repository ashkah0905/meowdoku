# Meowdoku

ネコを探す、マインスイーパ風のロジックパズルです。ブラウザで `index.html` を開くだけで遊べます。

## ルール

- 1色につきネコは1匹
- 各行にネコは1匹
- 各列にネコは1匹
- ネコ同士は上下左右斜めに隣接できません

## 遊び方

1. `index.html` をブラウザで開く
2. マスをタップして `空 -> × -> ネコ -> 空` の順に切り替える
3. ネコがいないと思うマスには `×` を置く
4. ネコがいると思うマスにはネコを置く
5. 「チェック」で現在のルール違反を確認する
6. 5匹すべて正しく置けたらクリア

## 機能

- 5x5盤面
- 固定レベル3問
- ネコ発見数表示
- ルール違反チェック
- ヒント
- チェック
- リセット
- レベル切り替え
- `localStorage` による途中保存
- スマホ幅向けレイアウト

## 構成

- `index.html`: 画面構造
- `styles.css`: 見た目とレスポンシブ対応
- `main.js`: レベル定義、入力、判定、保存、描画
